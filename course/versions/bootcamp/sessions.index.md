# Sessions

The bootcamp runs over five days, two sessions per day (morning and afternoon). The build is cumulative.

### Day 1 - Sensors and Motors
- [Analog Electronics](01_analog-electronics/README.md): atoms, electrons, sensors.
- [Magnets and Semiconductors](02_magnets-and-semiconductors/README.md): magnets, motors, transistors.

### Day 2 - Computers and Robotics
- [Digital Computers](03_digital-computers/README.md): data, logic, memory, computers.
- [Robot Control](04_robot-control/README.md): control and robotics.

### Day 3 - Systems and Networks
- [Software Systems](05_software-systems/README.md): power, systems, Linux, Python.
- [The Internet](06_the-internet/README.md): networks, websites, servers.

### Day 4 - Audio
- [Microphones and Speakers](07_microphones-and-speakers/README.md): audio input and output hardware.
- [Signal Processing](08_signal-processing/README.md): processing 1-D data.

### Day 5 - Images
- [Cameras](09_cameras/README.md): image acquisition hardware.
- [Computer Vision](10_computer-vision/README.md): processing 2-D data.

Start at Day 1 and work in order.
