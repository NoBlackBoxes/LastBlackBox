Welcome. Over five days you will build **NB3**, a robot designed from individual electrons up to a web-connected machine running computer vision and audio models. By the end of the week you will have the hardware, the code, and the mental model to extend any layer for your own experiments.

## The five days

### Day 1 - [Electronics and Sensors](sessions/01_electronics-and-sensors/README.md)
- Build the analog stack with no software in sight
  - Atoms, electrons, magnets, motors, transistors
  - **Project**: *Light sensor + hand-wound speaker + light-sensitive motor*

### Day 2 - [Arduino and Braitenberg](sessions/02_arduino-and-braitenberg/README.md)
- Add a programmable brain
  - Logic, memory, microcontrollers, PWM, servos
  - **Project**: *Light-controlled theremin and a full Braitenberg vehicle*

### Day 3 - [Linux and Python](sessions/03_linux-and-python/README.md)
- The robot grows a real computer
  - Power, operating systems, the command line, Python, serial protocols
  - **Project**: *Drive the robot from your laptop over SSH*

### Day 4 - [Web Stack and Senses](sessions/04_web-stack-and-senses/README.md)
- A robot you can see and talk through
  - Sockets, HTTP, HTML, CSS, JavaScript, microphones, speakers, cameras
  - **Project**: *Phone-controlled robot streaming its camera feed*

### Day 5 - [Open Projects](sessions/05_open-projects/README.md)
- Pick a track and ship it
  - Sensor streaming, audio DSP, computer vision, voice, full-stack
  - **Project**: *Your own NB3 extension, built and demoed*

## Before you arrive

A laptop with **VS Code**, **Git**, and the **Arduino IDE** installed. WiFi credentials handy (the robot connects to the venue network on Day 3). Familiarity with the command line and Python is helpful but not required; Day 3 covers both without dwelling.

The kit is provided.

## How to use these pages

The sessions are worked through **in order**. Each session is one continuous walkthrough: start at the top, watch the videos, do the tasks, move on. Hover any lesson thumbnail to play its preview. Repository links like [boxes/electrons](https://github.com/NoBlackBoxes/LastBlackBox/tree/master/boxes/electrons) point into the wider LBB repo for deeper reference; you do not need to read them on the day.

## Source material

Crick is a five-day reorganisation of the [Experimental Neuroscience Bootcamp (LBB-103, "enb")](https://github.com/NoBlackBoxes/LastBlackBox/tree/master/course/versions/enb). If you finish the week and want to dive deeper, the enb chapters carry additional detail and exercises.
