# Sessions

The Crick bootcamp runs over five days. The build is cumulative: each day adds layers to the robot you started the day before.

### Day 1 - [Electronics and Sensors](01_electronics-and-sensors/README.md)
- Build the analog stack with no software in sight
  - **Project**: *Light sensor + hand-wound speaker + light-sensitive motor*

### Day 2 - [Arduino and Braitenberg](02_arduino-and-braitenberg/README.md)
- Add a programmable brain
  - **Project**: *Light-controlled theremin and a full Braitenberg vehicle*

### Day 3 - [Linux and Python](03_linux-and-python/README.md)
- The robot grows a real computer
  - **Project**: *Drive the robot from your laptop over SSH*

### Day 4 - [Web Stack and Senses](04_web-stack-and-senses/README.md)
- A robot you can see and talk through
  - **Project**: *Phone-controlled robot streaming its camera feed*

### Day 5 - [Open Projects](05_open-projects/README.md)
- Pick a track and ship it
  - **Project**: *Your own NB3 extension, built and demoed*

Start at Day 1 and work in order.
