# Sessions

Four sessions building cumulatively to a Braitenberg vehicle.

### Session 1 - [Analog Electronics](01_analog-electronics/README.md)
- Atoms, electrons, and sensors.

### Session 2 - [Magnets and Semiconductors](02_magnets-and-semiconductors/README.md)
- Magnets, motors, and transistors.

### Session 3 - [Digital Computers](03_digital-computers/README.md)
- Data, logic, memory, and computers.

### Session 4 - [Robot Control](04_robot-control/README.md)
- Control and robotics.

Start at Session 1 and work in order.
